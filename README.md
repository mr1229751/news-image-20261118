"The World Daily Briefing" is a one-page newspaper that sums up the world's news of Wednesday 18 November 2026 in a single 1024x1024 image: a broadsheet front page carrying 19 verified dispatches from six continents — the US–Iran escalation in the Gulf as the lead package with a Hormuz tactical inset, the pre-Nvidia market rout with its own chart, Ukraine, Gaza, COP31, and the culture and sport wires — arranged around a filled-silhouette world map with 14 numbered pins. The design source is page.html; main.py is the entrypoint and simply copies the bundled entry.png into the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
